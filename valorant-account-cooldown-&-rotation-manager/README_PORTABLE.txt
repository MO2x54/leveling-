================================================================================
   VALORANT ROTATION & 19H COOLDOWN TRACKER (MO2A PRIVATE EDITION)
              GUIDE: HOW TO TRANSFER ACROSS COMPUTERS / DEVICES
================================================================================

1. DIRECT TRANSFER (USB FLASH DRIVE / ZIP / GOOGLE DRIVE / DISCORD):
-------------------------------------------------------------------
- Once you build the EXE using "build_exe.bat", go to the "dist" folder.
- You will find:
    - ValorantRotationTracker_Mo2a.exe
    - accounts.json (created automatically next to the .exe)

- To move to another PC / Laptop:
    1. Simply copy the folder containing "ValorantRotationTracker_Mo2a.exe" 
       and "accounts.json" onto your USB Flash Drive, or send it in a .zip.
    2. Paste it on the other computer (any folder: Desktop, Documents, D:\, etc.).
    3. Double-click "ValorantRotationTracker_Mo2a.exe" to launch immediately!
    * NOTE: The target PC does NOT need Python installed. The .exe is 100% standalone!


2. USING THE BUILT-IN EXPORT & IMPORT (BACKUP & TRANSFER):
----------------------------------------------------------
Whether you are using the Desktop .EXE program or the Web App:
- On Machine A (Old PC):
    - Click "💾 EXPORT" (or "Export Data JSON").
    - Save the file (e.g. accounts_backup_mo2a.json).
- On Machine B (New PC / Laptop / Another Browser):
    - Open the program or web app.
    - Click "📥 IMPORT" (or "Import Data").
    - Select your backup JSON file.
    - All accounts, live timers, levels, passwords, and regions are restored instantly!


3. COMPATIBILITY BETWEEN WEB APP & DESKTOP .EXE:
------------------------------------------------
- The JSON backup file is 100% cross-compatible:
  You can export from the Web App and import directly into the Desktop .EXE,
  or export from the Desktop .EXE and import into the Web App!
